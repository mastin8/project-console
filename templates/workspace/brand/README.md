# Il marchio di questo progetto

Deposita qui `logo.svg` o `logo.png` (e, per il tema scuro, `logo-dark.png`): l'intestazione del
coordinatore la usa subito, senza toccare codice.

Senza file, l'intestazione mostra il marchio di serie del coordinatore; se manca anche quello, un
monogramma con l'iniziale del nome del progetto.
